# Белый Ввоз — Платформа курсов по импорту из Китая

Полноценная платформа для продажи онлайн-курсов по белому импорту из Китая.

## Стек технологий

- **Frontend**: React 18 + Vite + React Router
- **Backend**: FastAPI + SQLAlchemy + SQLite (aiosqlite)
- **Авторизация**: JWT + 2FA (6-значный код)
- **AI-ассистент**: Виктория (интегрирован через Groq API)

## Функции

1. **Каталог курсов** — 6 курсов с описаниями, уроками и видео
2. **Регистрация/Авторизация** — email + пароль, 2FA, подтверждение email
3. **Личный кабинет** — прогресс обучения, настройки профиля
4. **Калькулятор таможенных пошлин** — 10 категорий товаров
5. **Система отзывов** — пользователи пишут отзывы, админ модерирует
6. **AI-чат** — ассистент «Виктория» отвечает на вопросы
7. **Вебинары** — анонсы и управление через админку
8. **Защита видео** — watermark, блокировка скачивания, DevTools
9. **Оплата СБП** — заглушка для подключения реального API
10. **Админ-панель** — управление курсами, пользователями, аналитика

## Запуск

### Backend

```bash
cd backend
pip install -e .
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Установить переменную `VITE_API_URL` для подключения к бэкенду:
```bash
VITE_API_URL=http://localhost:8000 npm run dev
```
